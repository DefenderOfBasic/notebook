Just put it anywhere publicly on the internet. Preferably NOT a google doc because that isn't very discoverable. More like on your own blog / substack.

If you prefer a more private space I recommend having a "personal notebook" via Obsidian / GitHub. This way you can have all your notes be public but it doesn't have to be super polished / it's an evolving thing.

See my guide [Host your Obsidian notebook on GitHub Pages for free](https://dev.to/defenderofbasic/host-your-obsidian-notebook-on-github-pages-for-free-8l1)

An example of this is my own notebook: https://defenderofbasic.github.io/notebook/. I have also started using the GitHub repo to maintain a public "review queue" so people can send me things to review and my write up is public: https://github.com/DefenderOfBasic/notebook/issues
